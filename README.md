# Double Jay Barbershop – booking site demo

A demo of the Double Jay Barbershop (TJ & U Complex, Rabai Road) WooCommerce booking site that runs entirely in the browser with WordPress Playground.

- Booking site: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/double-jay-demo/main/blueprint.json
- Store admin (services, prices, appointments): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/double-jay-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test appointments are not kept.
